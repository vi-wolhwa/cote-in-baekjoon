# ADR-0003: 기술 스택

- 상태: 승인
- 날짜: 2026-11-23
- 관련: 이슈 #5

## 결정

| 영역 | 선택 | 이유 |
|---|---|---|
| 언어 | TypeScript (strict) | 백준 DOM, 메시지, 실행 결과처럼 경계가 많아 타입이 실수를 줄인다 |
| 확장 프레임워크 | [WXT](https://wxt.dev) 0.21 | Vite 기반, MV3, 샌드박스 진입점, Edge 빌드, zip 패키징, HMR을 기본 제공. 2026-11 기준 활발히 유지보수됨 |
| UI | Preact 11 + TypeScript | 확장 용량이 중요하다. React 호환 API를 쓰면서 번들이 작다 |
| 코드 에디터 | CodeMirror 6 | CSP 문제를 일으키는 워커가 없고 번들이 작다. 테마·키맵을 세밀하게 맞출 수 있어 프로그래머스 에디터의 동작을 재현하기 좋다 |
| 수식 | MathJax 3 (패키지 포함) | 백준과 같은 렌더링 결과 |
| 단위 테스트 | Vitest | WXT 공식 지원 |
| E2E 테스트 | Playwright (Chromium, 확장 로드) | 실제 확장을 띄워 풀이 화면을 검증한다 |
| 린트·포맷 | ESLint (typescript-eslint) + Prettier | 생태계 표준. 설정이 단순하다 |
| 패키지 매니저 | npm | 추가 설치가 필요 없고, CI 캐시 설정이 단순하다 |
| Node | 24 LTS | 로컬 환경과 CI를 맞춘다 |

## 검토했지만 택하지 않은 것

- **Plasmo**: 2025-05 이후 릴리스가 없다.
- **CRXJS**: 다시 유지보수되고 있지만 zip 패키징과 다중 브라우저 빌드를 직접 구성해야 한다.
- **Monaco**: 번들이 3~5MB이고 전용 워커가 필요하다. 기본 로더가 CDN을 써서 웹스토어 정책을 피하려면 별도 설정이 필요하다. 언어 서비스 같은 장점도 이 제품에는 필요 없다.
- **React**: 동작은 같지만 번들이 크다. 필요하면 `preact/compat`으로 React 라이브러리를 쓴다.

## 결과

- 버전은 정확히 고정하고, Dependabot으로 업데이트 PR을 받는다.
- 한글 입력(IME)은 CodeMirror에서 문제가 생기기 쉽다. Chrome과 웨일에서 E2E로 확인한다.
