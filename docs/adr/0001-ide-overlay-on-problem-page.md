# ADR-0001: 풀이 화면을 백준 문제 페이지 위에 띄운다

- 상태: 승인
- 날짜: 2026-11-23
- 관련: PRD R2, 이슈 #3

## 배경

풀이 화면에는 백준 문제 본문(설명, 입출력, 예제, 이미지, 수식)이 필요하다. 백준에는 다음 제약이 있다.

- [이용 규칙](https://help.acmicpc.net/rule)이 웹 스크래핑을 금지한다.
- 약관(2026-11-20 시행)이 문제의 외부 복제·재배포를 제한한다.
- `X-Frame-Options: DENY`라서 백준 페이지를 다른 페이지의 iframe에 넣을 수 없다.

## 검토한 선택지

1. **확장 전용 탭**에서 문제 페이지를 따로 요청(fetch)해 표시한다.
   - 사용자가 보고 있는 것과 별개로 백준에 요청이 한 번 더 간다.
   - 문제를 확장 쪽으로 복제하는 모양이 된다.
2. **문제 페이지 위 오버레이**: 사용자가 이미 연 문제 페이지의 DOM에서 본문을 읽고, 그 위에 풀이 화면을 전체 화면으로 띄운다.

## 결정

2번을 택한다.

- 콘텐츠 스크립트가 `/problem/{id}` 페이지에서 본문을 읽는다.
- 확장 페이지 `ide.html`을 전체 화면 iframe으로 띄우고, 문제 데이터를 메시지로 넘긴다.
- iframe을 쓰는 이유는 백준 CSS와 스크립트로부터 화면을 격리하고, 확장의 CSP를 그대로 쓰기 위해서다.
- 풀이 화면을 닫으면 원래 문제 페이지가 그대로 보인다.

**읽는 위치 (2026-11 기준)**

| 항목 | 선택자 |
|---|---|
| 제목 | `#problem_title` |
| 시간·메모리 제한 | `#problem-info` 첫 행 |
| 본문 섹션 | `#problem_description`, `#problem_input`, `#problem_output`, `#problem_limit`, `#problem_hint` |
| 예제 | `#sample-input-N`, `#sample-output-N` |
| 문제 유형 라벨 | `.problem-label-{spj,interactive,func,subtask,...}` |

**표시 방법**
- 이미지의 상대 경로는 `https://acmicpc.net` 기준으로 바꾼다.
- 수식은 백준과 같은 MathJax 3 설정(`$…$`, `\(…\)`, `$$…$$`, `\[…\]`)으로 렌더링한다. MathJax는 확장에 포함한다.
- 문제 HTML은 신뢰하지 않는 입력으로 보고, 허용 목록 방식으로 정제한 뒤 표시한다.

## 결과

- 백준에 추가 요청이 없고, 문제를 저장하거나 복제하지 않는다.
- 백준 HTML 구조가 바뀌면 깨진다. 파서를 한 모듈에 모으고, 저장해 둔 HTML 샘플로 테스트한다.
- 인터랙티브·함수 구현 문제는 표준 입출력 실행이 맞지 않는다. 라벨로 감지해 '코드 실행'을 막고 이유를 안내한다.
- 모의 시험(M4)은 여러 문제를 다룬다. 문제마다 실제 문제 페이지를 열어 오버레이를 띄우는 방식으로 설계한다.
