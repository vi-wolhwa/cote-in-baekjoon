# ADR-0015: 백업과 복원 없애기

- 상태: 채택
- 날짜: 2026-11-25
- 관련: #209, #42(백업과 복원), ADR-0012 개정 3(코드 임시 저장), ADR-0005(모의 시험)

## 배경

백업과 복원(#42)은 "확장을 삭제하면 코드가 사라진다"는 위험 때문에 만들었다. 0.21.0(#185)부터 확장은 과거 풀이를 저장하지 않는다.

- 제출한 코드는 백준 '내 제출'에서 다시 읽는다.
- 편집 중 코드는 임시 저장이다. 연습은 3시간 안에만 복원하고, 2일 뒤 정리한다.

검토(#209) 결과 백업은 지킬 것이 거의 없었다.

- 백업 속 코드는 복원해도 편집기가 열지 않거나(3시간 초과) 다음 시작 때 지워진다(2일 초과).
- 그런데도 팝업과 도움말은 "코드를 백업해 두라"고 안내했다.
- '바꾸기' 복원은 진행 중인 모의 시험 기록을 지울 수 있었다.

남는 가치는 직접 만든 테스트 케이스, 고친 형식, 모의 시험 기록을 다른 PC로 옮기는 것이었다. 제품 책임자는 축소 대신 제거를 골랐다(2026-11-25).

## 결정

- 팝업의 '백업' 탭, 옵션 페이지(복원), 풀이 화면 상단의 '백업과 복원'을 없앤다. 옵션 페이지가 없어지므로 매니페스트에서 `options_ui`도 빠진다.
- `src/shared/backup.ts`, `backup-download.ts`와 그 테스트를 지운다.
- 저장 데이터는 그대로 둔다. 키를 옮기거나 지우는 일은 없다.
- 안내를 고친다. 확장을 삭제하면 브라우저 데이터가 지워지고, 제출한 코드는 백준에 남는다(도움말, README, 개인정보처리방침, 스토어 설명).
- `unlimitedStorage`는 유지한다. 코드는 짧게 남지만, 모의 시험 기록이 시험마다 문제 본문을 최대 8개 담고 계속 쌓이므로 10MB 제한에 걸릴 수 있다. 권한 사유를 이에 맞게 고친다.

## 결과

- 사용자가 PC를 옮기거나 다시 설치하면 테스트 케이스, 고친 형식, 모의 시험 기록, 설정이 사라진다. 요청이 오면 그 데이터만 대상으로 다시 검토한다. 예를 들어 설정만 `storage.sync`로 동기화할 수 있다.
- 예전에 내보낸 백업 파일은 더 이상 읽지 않는다. 공개 전이라 영향받는 사용자는 없다.
