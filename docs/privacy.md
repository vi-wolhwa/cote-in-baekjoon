# 개인정보처리방침

코딩테스트 in 백준(이하 "확장 프로그램")의 개인정보 처리 방식입니다.

- 시행일: 2026-11-24
- 문의: GitHub 저장소의 이슈

## 1. 수집하는 개인정보

확장 프로그램은 개인정보를 수집하지 않습니다. 운영자가 관리하는 서버가 없고, 사용 통계·광고·분석 도구도 쓰지 않습니다. 사용자가 입력한 내용을 운영자나 제3자에게 보내지 않습니다. 모의 시험을 만들 때만 고른 조건(과 '이미 푼 문제 빼기'를 켰다면 백준 아이디)을 solved.ac에 보냅니다(4장).

## 2. 브라우저에 저장하는 데이터

아래 데이터는 사용자의 브라우저 안(`chrome.storage`)에만 저장됩니다.

| 데이터 | 목적 | 보관 기간 |
| --- | --- | --- |
| 문제별 코드, 추가한 테스트 케이스 | 다시 열었을 때 이어서 풀기 | 사용자가 지우거나 확장 프로그램을 삭제할 때까지 |
| 언어, 에디터 키맵, 화면 분할 비율, 자동 제출 설정 | 설정 유지 | 위와 같음 |
| 문제별 마지막 채점 결과(결과, 메모리, 시간) | 풀이 화면에 결과 표시 | 위와 같음 |
| 문제별 제출 기록(제출한 코드, 언어, 제출 시각, 채점 결과·제출 번호) | 풀이 화면의 '제출 기록' 탭 | 문제마다 최근 50개. 사용자가 지우거나 확장 프로그램을 삭제할 때까지 |
| 제출 중인 코드와 제출 탭 정보 | 제출 페이지에 코드 채우기, 채점 상태 표시 | 브라우저를 닫을 때까지(세션 저장소) |
| 모의 시험 기록(조건, 문제 번호·제목·본문, 시작·끝 시각, 제출 시각과 결과), 마지막으로 고른 시험 조건 | 시험 화면과 결과 화면 | 사용자가 지우거나 확장 프로그램을 삭제할 때까지 |
| 로그인된 백준 아이디 | 모의 시험에서 이미 푼 문제 빼기 | 다음에 백준 페이지를 열 때 갱신. 백업 파일에는 넣지 않음 |

확장 프로그램을 삭제하면 위 데이터도 함께 지워집니다. 삭제 전에 옵션 페이지의 "백업과 복원"에서 JSON 파일로 내보낼 수 있습니다. 내보낸 파일은 사용자의 기기에만 저장되고, 확장 프로그램은 이 파일을 어디에도 보내지 않습니다.

## 3. 백준(acmicpc.net)과 주고받는 정보

확장 프로그램은 사용자가 백준에서 하는 일을 돕기만 합니다. 로그인 정보나 쿠키를 읽거나 저장하지 않습니다.

- **문제 페이지**: 사용자가 연 문제 페이지에서 문제 내용과 예제를 읽어 풀이 화면에 보여 줍니다. 따로 요청을 보내지 않습니다.
- **제출**: 사용자가 "제출하기"를 누르면 백준의 공식 제출 페이지를 같은 창의 뒤쪽 탭으로 열고 언어와 코드를 채운 뒤 백준의 제출 버튼을 대신 누릅니다. 제출은 사용자 계정으로 백준에 직접 전송되고, 채점이 끝나면 그 탭을 닫습니다.
- **채점 결과**: 사용자가 방금 한 제출의 채점 결과를 채점 현황 페이지에서 읽습니다. 실시간 갱신이 멈추면 그 제출의 결과만 백준에 다시 묻습니다(최대 10분, 간격을 늘려 가며). 결과를 읽기 전에 그 탭이 닫혀 사용자가 "결과 다시 확인"을 누르면, 사용자 자신의 채점 현황 페이지를 뒤쪽 탭으로 한 번 열어 결과를 읽고 닫습니다.
- **제출 기록 탭의 채점 현황**: 사용자가 '제출 기록' 탭을 열 때, 그 문제의 사용자 자신의 채점 현황(`/status?problem_id=…&user_id=…`)과 그 문제의 전체 채점 현황(`/status?problem_id=…`) 첫 페이지를 뒤쪽 탭으로 하나씩 잠깐 열어 제출 번호·아이디·결과·메모리·시간·언어·코드 길이·제출 시각을 읽어 보여 주고 탭을 닫습니다. 다음 페이지는 사용자가 페이지를 넘길 때만 읽습니다. 읽은 내용은 저장하지 않고 화면에 1분 동안만 둡니다. 소스 코드는 읽지 않고, 제출 번호를 누르면 백준의 소스 페이지를 새 탭으로 엽니다.
- **언어 설정**: 고른 언어가 백준 언어 목록에 없으면 백준 언어 설정 페이지로 안내합니다.
- **모의 시험 문제**: 사용자가 모의 시험을 시작하면 그 시험의 문제(최대 8개) 페이지를 같은 창의 뒤쪽 탭으로 하나씩 열어(사용자가 문제 페이지를 여는 것과 같은 일반 방문) 문제 내용을 읽고 탭을 닫습니다. 읽은 내용은 시험 기록에 저장해 다시 열지 않습니다.
- **모의 시험 제출**: 시험 중에는 아무것도 제출하지 않고 답안을 브라우저에만 저장합니다. 시험이 끝나면 저장한 답안을 위 '제출'과 같은 방식으로 하나씩 백준에 제출합니다.
- **로그인 아이디**: 백준 페이지 상단에 보이는 로그인 아이디를 읽어 브라우저에 저장합니다(모의 시험의 '이미 푼 문제 빼기'용). 비밀번호나 쿠키는 읽지 않습니다.

사용자가 버튼을 누르지 않았는데 백준에 요청을 보내거나 페이지를 모아 오지 않습니다.

## 4. solved.ac와 주고받는 정보

모의 시험에서 사용자가 '시험 시작'을 누를 때만 solved.ac의 공개 API에 문제 검색을 요청합니다. 처음 한 번은 브라우저가 solved.ac 접근을 허용할지 묻습니다.

- 보내는 것: 고른 조건(난이도, 알고리즘), 그리고 '이미 푼 문제 빼기'를 켰다면 백준 아이디. 쿠키는 보내지 않습니다.
- 받는 것: 조건에 맞는 문제 번호, 제목, 난이도
- 미리 받아 두거나 자동으로 다시 요청하지 않습니다.

## 5. 코드 실행

"코드 실행"은 사용자의 브라우저 안에서만 이루어집니다. 코드는 네트워크에 접근할 수 없는 격리된 페이지에서 실행되며, 실행에 쓰는 Python·C++ 실행 환경도 확장 프로그램에 들어 있어 외부에서 내려받지 않습니다.

## 6. 권한을 쓰는 이유

| 권한 | 이유 |
| --- | --- |
| `storage` | 2장의 데이터를 브라우저에 저장 |
| `unlimitedStorage` | 문제 수가 많아져도 코드가 저장 용량 제한(10MB)에 막히지 않도록 |
| acmicpc.net 페이지 접근 | 문제 페이지에 풀이 화면 열기, 제출 페이지 채우기, 채점 결과 읽기, 언어 설정 안내, 모의 시험 문제 읽기(뒤쪽 탭으로 연 문제 페이지) |
| solved.ac 접근(선택, 처음 '시험 시작' 때 물음) | 모의 시험 문제 고르기 |
