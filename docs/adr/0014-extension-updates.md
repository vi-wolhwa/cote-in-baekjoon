# ADR-0014: 확장 업데이트 대응

- 상태: 채택
- 날짜: 2026-11-25
- 관련: #204, ADR-0013(웹스토어 업로드), `docs/ops/maintenance.md` 3장

## 배경

제품 책임자가 확장 자동 업데이트가 가능한지 검토하라고 했다. 검토 결과는 다음과 같다.

- **웹스토어 설치**(크롬, 엣지 애드온, 웨일 스토어): 브라우저가 시작할 때와 몇 시간마다 새 버전을 확인해 자동으로 설치한다. 확장이 따로 만들 것은 없다.
- **설치 시점**: 새 버전은 확장이 쉬고(idle) 있을 때 설치된다. MV3에서는 서비스 워커가 멈춰 있고 확장 페이지(팝업, 옵션, 확장 탭 등)가 열려 있지 않아야 한다. 콘텐츠 스크립트는 상관없다. 이벤트가 계속 서비스 워커를 깨우면 브라우저를 다시 시작할 때까지 미뤄진다.
- **GitHub zip(압축 해제 설치)**: 자동 업데이트가 불가능하다. 크롬은 윈도·맥에서 웹스토어 밖 CRX 설치와 자체 `update_url`을 막는다(기업 정책은 예외). 공개 뒤에는 웹스토어 설치만 안내한다.

그래서 문제는 업데이트를 *하는* 방법이 아니라, 업데이트가 풀이 중인 사용자를 *방해하지 않게* 하는 것이다.

1. 풀이 화면은 백준 문제 페이지 위에 확장 페이지(`ide.html`)를 iframe으로 띄운 것이다. 이 iframe이 '열린 확장 페이지'로 쳐지면 풀이 중에는 업데이트가 미뤄진다. 쳐지지 않으면 풀이 중에 업데이트되어 화면 전체를 덮은 빈 iframe만 남는다.
2. 업데이트 뒤 이미 열린 백준 탭의 콘텐츠 스크립트는 확장과 끊긴다("Extension context invalidated"). '코딩테스트'·'모의시험' 버튼이 아무 반응 없이 실패한다.
3. 사용자는 업데이트를 알 수 없다.

## 결정

1. **업데이트 시점은 브라우저에 맡긴다.** `runtime.onUpdateAvailable`로 받아 `runtime.reload()`를 부르지 않는다. 일찍 적용하면 2번 문제만 늘어난다. 시험 화면과 풀이 화면 같은 확장 페이지가 열려 있으면 브라우저가 미룬다.
2. **끊긴 콘텐츠 스크립트**(`src/boj/extension-alive.ts`): `runtime.id`가 없어지면 확장이 끊긴 것이다.
   - 버튼을 누를 때 확인하고, 끊겼으면 "확장 프로그램이 업데이트되었습니다. 페이지를 새로고침할까요?"를 묻는다.
   - 풀이 화면이 열려 있는 동안 2초마다 같은 값을 확인한다(요청 없음). 끊기면 빈 iframe을 걷고 같은 질문을 한다. 1번 iframe이 업데이트를 미루지 못하는 경우의 안전장치다. 코드는 편집하는 동안 자동 저장되므로(ADR-0012 개정 3) 새로고침해도 복원된다.
3. **새 버전 안내**(`src/shared/update-notice.ts`):
   - `runtime.onInstalled`(reason `update`, 버전이 오른 경우만)에서 `update:notice`를 저장한다. 툴바 아이콘에 `N` 배지를 단다.
   - 팝업은 이 값을 "vX.Y.Z로 업데이트되었습니다 · 변경 내용"으로 보여 주고, 열리면 배지를 지운다. 닫기를 누르면 값을 지운다.
   - 같은 버전을 다시 불러오는 개발 중 새로고침과 버전이 내려가는 경우에는 안내하지 않는다. 백업에는 들어가지 않는다.
   - '변경 내용'은 GitHub 릴리스를 연다. 저장소가 비공개인 동안에는 사용자가 볼 수 없으므로 #200의 공개 위치 결정을 따른다.
4. **저장 데이터 형식이 바뀌면** `runtime.onInstalled`의 정리 단계(`cleanupStorage`)에서 옮긴다. 옛 키를 한 버전 이상 계속 읽는다(maintenance.md 3장).

## 결과

- 1번(iframe이 업데이트를 미루는지)은 실제 스토어 빌드로만 확인할 수 있다. 첫 게시를 테스터 전용으로 하고(#205), 두 번째 버전을 올려 확인한다(#204).
- 업데이트 확인을 앞당기는 `runtime.requestUpdateCheck()`는 쓰지 않는다. 브라우저가 호출 횟수를 제한하고, 설치는 어차피 확장이 쉴 때 된다.
