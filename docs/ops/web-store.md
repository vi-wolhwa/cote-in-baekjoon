## 패키지 탭

- 올릴 파일: GitHub 릴리스의 `cote-in-baekjoon-<버전>-chrome.zip`(`gh release download v<버전> -p '*-chrome.zip'`). `.output/`에 남은 예전 빌드 zip을 올리지 않도록 버전을 확인한다(첫 업로드 때 0.1.0 zip을 잘못 올린 적이 있음).

## 개인정보 보호 관행 탭

**단일 목적**

> 백준(acmicpc.net) 문제를 코딩테스트와 같은 풀이 화면에서 풀도록 돕습니다. 문제 읽기, 코드 작성과 예제 실행, 백준 제출과 채점 결과·제출 기록 확인, 백준 문제로 만든 모의 시험이 모두 이 풀이 화면 안의 기능입니다.

**권한별 사용 이유**

| 항목 | 답변 |
| --- | --- |
| `storage` | 사용자가 작성한 코드, 테스트 케이스, 설정, 마지막 채점 결과를 브라우저에 저장합니다. |
| `unlimitedStorage` | 모의 시험 기록(시험마다 문제 본문 최대 8개)과 테스트 케이스가 쌓여도 10MB 제한에 걸리지 않도록 합니다. 데이터는 기기 밖으로 나가지 않습니다. |
| 호스트 권한 (acmicpc.net) | 문제 페이지에 풀이 화면을 띄우고, 제출 페이지에 언어와 코드를 채우고, 사용자 제출의 채점 결과를 읽습니다. 모의 시험에서는 사용자가 연 문제의 페이지를 뒤쪽 탭으로 한 번 열어 내용을 읽고 닫습니다. |
| `activeTab` | 툴바 팝업을 열었을 때 지금 탭의 주소를 읽어, 백준 문제 페이지라면 그 문제를 바로 풀 수 있게 합니다. 팝업을 연 탭에만 적용됩니다. |
| 선택 호스트 권한 (solved.ac) | 모의 시험을 만들 때 사용자가 고른 조건에 맞는 문제를 solved.ac 공개 API에서 고릅니다. 처음 시험을 만들 때만 묻습니다. |

> 대시보드에 호스트 권한 칸이 하나뿐이면 acmicpc.net과 solved.ac 두 줄을 그 칸에 함께 적는다.

**원격 코드 사용**: 아니요. 모든 스크립트와 실행 환경(Pyodide, Clang)은 패키지에 포함되어 있습니다.

**데이터 사용**: 운영자는 아무것도 수집하지 않습니다. 다만 번역 기능이 외국어 문제 본문을 구글 번역으로 보내므로(#201) 아래처럼 신고합니다.

- **웹사이트 콘텐츠: 해당** — 사용 목적 '앱 기능'. 외국어 문제를 한국어로 번역하려고 그 문제 본문을 구글 번역(`translate.googleapis.com`)에 보냅니다. 코드·아이디·쿠키는 보내지 않고, 운영자는 받지 않습니다.
- 나머지(개인 식별 정보, 건강, 금융, 인증 정보, 개인 커뮤니케이션, 위치, 웹 기록, 사용자 활동): 해당 없음

> 백준 문제 페이지는 화면에 보여 주려고 읽기만 하고 기기 밖으로 보내지 않습니다. 번역은 지금 방식(구글 번역, 자동)을 유지한다(2026-11-25 제품 책임자, #201).

**인증 항목**: 세 가지 모두 체크합니다.

- 승인된 사용 사례 외에 사용자 데이터를 제3자에게 판매하거나 전송하지 않음
- 단일 목적과 관계없는 목적으로 사용자 데이터를 사용하거나 전송하지 않음
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음

**개인정보처리방침 URL**: https://github.com/vi-wolhwa/cote-in-baekjoon/blob/main/docs/privacy.md (저장소 공개, 2026-11-25)
