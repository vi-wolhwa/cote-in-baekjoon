# ADR-0010: 외국어 문제 자동 번역

- 상태: 승인 (2026-11-24), 같은 날 개정
- 관련: `src/ide/translate/`, 화면 명세 §7

## 배경

백준에는 영어, 일본어, 폴란드어 등 한국어가 아닌 문제가 많다. 제품 책임자가 다른 언어로 된 문제를 자동으로 번역하고, 원문으로 보는 토글을 두라고 요청했다(2026-11-24). 지원할 브라우저는 Chrome, Edge, Whale이다.

처음에는 브라우저 내장 번역기(Translator API, 기기 안 번역)만 썼는데, 검증해 보니 두 가지 문제가 있었다.
- Edge는 API는 있지만 영어→한국어 쌍을 제공하지 않아 번역되지 않았다. Whale에도 쓸 수 있는 내장 번역 API가 없다.
- Chrome의 기기 안 모델은 코드·수식 자리표시(`[3]`)를 문장 끝으로 옮겨, 인라인 코드가 문단 끝에 몰렸다.

## 결정

- **웹 번역을 먼저 쓴다**: Google 번역의 공개 엔드포인트(`translate.googleapis.com/translate_a/single`, 번역 위젯이 쓰는 것)를 쓴다.
  - Chrome·Edge·Whale 모두에서 같은 결과를 내고, 키·비용·호스트 권한이 없다(모든 출처에 CORS 허용).
  - 섹션마다 문단을 줄바꿈으로 묶어 한 번에 보낸다. 줄 수가 맞지 않으면 문단마다 따로 보낸다.
- **외부로 보내는 것**: 한국어가 아닌 문제의 본문만 보낸다(공개된 문제 텍스트). 코드, 예제, 계정 정보는 보내지 않는다. 한국어 문제는 글자 체계로 판정해 아예 보내지 않는다.
- **기기 안 번역은 대체 경로**: 웹 번역이 실패하면(오프라인, 차단) 내장 번역기를 쓴다. 모델을 처음 받아야 하면 '한국어로 번역' 버튼을 보인다(다운로드에 클릭이 필요하다). 둘 다 안 되면 "번역하지 못해 원문으로 보여요."와 '다시 시도'를 보인다.
- **원문 보기**: '번역 / 원문' 토글로 바꾸고, 고른 쪽을 기억한다(`ui:translate`). 원문을 고르면 다음 문제는 '한국어로 번역'을 눌러야 번역한다.
- **구조 보존**
  - 문단·목록 항목·표 칸마다 한 문장으로 번역한다. 수식(`$…$`, `\(…\)`), 코드, 위·아래 첨자, 그림, 하위 블록은 이름처럼 보이는 표시(`ZQX3`)로 바꿨다가 번역 뒤 되돌린다.
  - 번역기는 이 표시를 이름으로 다뤄 한국어 어순에 맞는 제자리에 둔다(`ZQX3이 짝수이면 ZQX1을 출력한다`).
  - 표시를 잃은 블록은 글 조각마다 따로 번역해, 마크업이 늘 남는다. 예제 입출력과 `pre`는 번역하지 않는다.
- **조사 맞추기**
  - 번역기는 표시(`ZQX1`)의 발음에 맞춰 조사를 붙인다. 그래서 되돌린 코드·수식 바로 뒤의 조사(이/가, 을/를, 은/는, 과/와, 으로/로)를 실제 내용의 끝소리에 맞게 고친다(`YES를`, `N이`, `b로`).
  - 끝소리는 한글이면 받침으로, 숫자와 영문 글자는 한국어로 읽을 때 기준으로 판단한다(1 일, 3 삼, L 엘, N 엔).
  - 판단할 수 없으면 그대로 둔다.

## 결과

- Chrome, Edge, Whale에서 같은 방식으로 번역된다. 인라인 코드와 수식이 문장 속 제자리에 남는다.
- 공개 엔드포인트는 공식 API가 아니어서 막히거나 바뀔 수 있다. 그때는 기기 안 번역으로 넘어가고, 그마저 없으면 원문을 보인다. 필요하면 키가 있는 공식 API로 바꿀 수 있다(비용은 제품 책임자 결정).
- 기계 번역이므로 막대에 "…에서 기계 번역했어요"를 적고, 원문으로 언제든 바꿀 수 있다.
