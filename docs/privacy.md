# 개인정보처리방침

코딩테스트 in 백준(이하 "확장 프로그램")의 개인정보 처리 방식입니다.

- 시행일: 2026-11-24
- 문의: GitHub 저장소의 이슈

## 1. 수집하는 개인정보

확장 프로그램은 개인정보를 수집하지 않습니다. 운영자가 관리하는 서버가 없고, 사용 통계·광고·분석 도구도 쓰지 않습니다. 사용자가 입력한 내용을 운영자나 제3자에게 보내지 않습니다.

## 2. 브라우저에 저장하는 데이터

아래 데이터는 사용자의 브라우저 안(`chrome.storage`)에만 저장됩니다.

| 데이터 | 목적 | 보관 기간 |
| --- | --- | --- |
| 문제별 코드, 추가한 테스트 케이스 | 다시 열었을 때 이어서 풀기 | 사용자가 지우거나 확장 프로그램을 삭제할 때까지 |
| 언어, 에디터 키맵, 화면 분할 비율, 자동 제출 설정 | 설정 유지 | 위와 같음 |
| 문제별 마지막 채점 결과(결과, 메모리, 시간) | 풀이 화면에 결과 표시 | 위와 같음 |
| 제출 중인 코드와 제출 창 정보 | 제출 페이지에 코드 채우기 | 브라우저를 닫을 때까지(세션 저장소) |

확장 프로그램을 삭제하면 위 데이터도 함께 지워집니다.

## 3. 백준(acmicpc.net)과 주고받는 정보

확장 프로그램은 사용자가 백준에서 하는 일을 돕기만 합니다. 로그인 정보나 쿠키를 읽거나 저장하지 않습니다.

- **문제 페이지**: 사용자가 연 문제 페이지에서 문제 내용과 예제를 읽어 풀이 화면에 보여 줍니다. 따로 요청을 보내지 않습니다.
- **제출**: 사용자가 "제출 후 채점하기"를 누르면 백준의 공식 제출 페이지를 열고 언어와 코드를 채웁니다. 자동 제출을 켜 두면 백준의 제출 버튼을 대신 누릅니다. 제출은 사용자 계정으로 백준에 직접 전송됩니다.
- **채점 결과**: 사용자가 방금 한 제출의 채점 결과를 채점 현황 페이지에서 읽습니다. 실시간 갱신이 멈추면 그 제출의 결과만 백준에 다시 묻습니다(최대 10분, 간격을 늘려 가며).
- **언어 설정**: 고른 언어가 백준 언어 목록에 없으면 백준 언어 설정 페이지로 안내합니다.

사용자가 버튼을 누르지 않았는데 백준에 요청을 보내거나 페이지를 모아 오지 않습니다.

## 4. 코드 실행

"코드 실행"은 사용자의 브라우저 안에서만 이루어집니다. 코드는 네트워크에 접근할 수 없는 격리된 페이지에서 실행되며, 실행에 쓰는 Python·C++ 실행 환경도 확장 프로그램에 들어 있어 외부에서 내려받지 않습니다.

## 5. 권한을 쓰는 이유

| 권한 | 이유 |
| --- | --- |
| `storage` | 2장의 데이터를 브라우저에 저장 |
| `unlimitedStorage` | 문제 수가 많아져도 코드가 저장 용량 제한(10MB)에 막히지 않도록 |
| acmicpc.net 페이지 접근 | 문제 페이지에 풀이 화면 열기, 제출 페이지 채우기, 채점 결과 읽기, 언어 설정 안내 |
