# 웹스토어 제출 자료

크롬 웹스토어 개발자 대시보드에 넣을 내용의 초안입니다. 게시는 #44에서 제품 책임자가 승인한 뒤에만 합니다.

## 개인정보 보호 관행 탭

**단일 목적**

> 백준(acmicpc.net) 문제를 코딩테스트와 같은 풀이 화면에서 풀고, 작성한 코드를 백준 제출 페이지로 옮겨 제출하도록 돕습니다.

**권한별 사용 이유**

| 항목 | 답변 |
| --- | --- |
| `storage` | 사용자가 작성한 코드, 테스트 케이스, 설정, 마지막 채점 결과를 브라우저에 저장합니다. |
| `unlimitedStorage` | 많은 문제의 코드를 저장해도 10MB 제한에 걸리지 않도록 합니다. 데이터는 기기 밖으로 나가지 않습니다. |
| 호스트 권한 (acmicpc.net) | 문제 페이지에 풀이 화면을 띄우고, 제출 페이지에 언어와 코드를 채우고, 사용자 제출의 채점 결과를 읽습니다. |

**원격 코드 사용**: 아니요. 모든 스크립트와 실행 환경(Pyodide, Clang)은 패키지에 포함되어 있습니다.

**데이터 사용**: 수집하는 데이터 없음. 아래 항목 모두 해당 없음으로 표시합니다.

- 개인 식별 정보, 건강 정보, 금융 정보, 인증 정보, 개인 커뮤니케이션, 위치, 웹 기록, 사용자 활동, 웹사이트 콘텐츠

> "웹사이트 콘텐츠"는 문제 내용을 화면에 보여 주기 위해 읽지만 수집하거나 전송하지 않으므로 해당 없음으로 둡니다. 심사에서 질문이 오면 이 설명으로 답합니다.

**인증 항목**: 세 가지 모두 체크합니다.

- 승인된 사용 사례 외에 사용자 데이터를 제3자에게 판매하거나 전송하지 않음
- 단일 목적과 관계없는 목적으로 사용자 데이터를 사용하거나 전송하지 않음
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음

**개인정보처리방침 URL**: `docs/privacy.md`를 공개 주소로 게시해야 합니다. 저장소가 비공개인 동안에는 쓸 수 없으므로 #44에서 게시 위치를 정합니다(저장소 공개 후 GitHub 페이지, 또는 GitHub Pages).
