🧑‍💻 백준 문제를 실제 코딩테스트 시험 화면처럼 풀어 보세요.

백준(acmicpc.net) 문제 페이지에 생기는 [코딩테스트] 버튼을 누르면, 기업 코딩테스트와 비슷한 풀이 화면이 열립니다. 문제 읽기 → 코드 작성 → 예제 실행 → 제출까지 한 화면에서 끝낼 수 있습니다.

※ 이 확장 프로그램은 백준 온라인 저지(스타트링크)와 관계없는 비공식 프로그램입니다.

✅ 시간을 재며 여러 문제를 시험처럼 풀어 보고 싶은 분
✅ 에디터와 백준 사이를 오가며 복사·붙여넣기 하는 것이 번거로운 분

🚀 사용 방법 (3단계)
━━━━━━━━━━━━━━━━━━━━

1️⃣ 백준 문제 페이지를 엽니다.
2️⃣ 문제 메뉴에 생긴 [코딩테스트] 버튼을 누릅니다.
3️⃣ 코드를 쓰고 [코드 실행]으로 예제를 확인한 뒤 [제출하기]를 누릅니다.

💡 모의 시험은 문제 메뉴의 [모의시험] 버튼이나 툴바의 확장 프로그램 아이콘에서 시작합니다.


━━━━━━━━━━━━━━━━━━━━
✨ 주요 기능
━━━━━━━━━━━━━━━━━━━━

🖥️ 한 화면에서 풀기
  • 왼쪽에는 문제와 제출 기록, 오른쪽에는 에디터와 실행 결과가 보입니다.
  • 수식과 예제 입력·출력을 백준과 같게 보여 줍니다.
  • 🌐 영어 등 외국어 문제는 한국어로 번역해 보여 줍니다. 원문도 볼 수 있습니다.
  • 🌙 다크·라이트 테마, ⌨️ sublime·vim·emacs 키맵, ⏱️ 스톱워치와 타이머를 지원합니다.

▶️ 브라우저에서 바로 실행
  • 실행 언어: C, C++(14/17/20), Python 3, Java 8/11, JavaScript, TypeScript
  • 예제와 직접 추가한 테스트 케이스로 실행하고, 통과 여부와 기댓값과의 차이를 보여 줍니다.
  • 📦 실행 환경이 확장 프로그램 안에 들어 있어 따로 설치할 것이 없습니다.
  • 🔒 코드는 인터넷이 차단된 격리된 공간에서 실행됩니다.
  • Kotlin, Rust, Go, Swift, C#, Ruby는 작성과 제출만 할 수 있습니다.

🧩 solution 함수로 풀기
  • 입출력 코드 없이 solution 함수만 작성하는 코딩테스트 방식으로 풀 수 있습니다.
  • 많이 푼 문제에는 입출력 형식이 미리 준비되어 있고, 예제는 '입출력 예' 표로 보여 줍니다.

📝 모의 시험
  • 난이도와 알고리즘 분류를 골라 시간 제한이 있는 시험 세트(최대 8문제)를 만듭니다.
  • 문제 고르기에는 solved.ac의 공개 정보를 사용합니다.
  • 시험 중에는 아무것도 제출하지 않습니다. 시험이 끝나면 답안을 백준에 차례로 제출하고 결과를 모아 보여 줍니다.

📤 백준으로 제출
  • [제출하기]를 누르면 백준 제출 페이지가 뒤쪽 탭에서 열리고, 언어와 코드가 자동으로 채워집니다.
  • 제출 버튼까지 자동으로 누릅니다. 제출 직전 잠깐 동안 취소할 수 있습니다.
  • ⏳ 채점 중에는 진행 상황이, ✔️ 채점이 끝나면 결과가 풀이 화면에 바로 나타납니다.

📊 제출 기록
  • 그 문제의 '내 제출', '맞힌 사람', '숏코딩' 목록을 풀이 화면 안에서 봅니다.
  • 공개된 코드를 열어 보고, 내 지난 코드를 에디터로 불러올 수 있습니다.
  • 목록은 보기를 열 때 백준에서 한 페이지씩 읽어 옵니다.
