# 자주 묻는 질문과 해결 방법

확장 팝업의 **도움말** 탭과 같은 내용입니다. 해결되지 않으면 [문제 신고](https://github.com/vi-wolhwa/cote-in-baekjoon/issues/new/choose)를 남겨 주세요.

## 풀이 버튼이 안 보여요

- 백준 **문제 페이지**(`acmicpc.net/problem/번호`)에서만 문제 위 메뉴의 "N번"과 "제출" 사이에 "코딩테스트" 버튼이 나옵니다.
- 확장을 설치하거나 업데이트한 직후에는 열려 있던 백준 탭을 새로고침해 주세요.
- `chrome://extensions`에서 확장이 켜져 있는지 확인해 주세요.

## 자동 제출이 안 돼요

- 제출은 팝업 없이 **뒤쪽 탭**에서 진행됩니다. 그 탭에 **보안 확인**(그림 고르기 등)이 나오면 자동으로 누르지 않고 "직접 확인이 필요해요"가 뜹니다. **직접 확인**을 눌러 그 탭에서 제출해 주세요.
- 고른 언어가 백준 **언어 목록**에 없으면 언어 설정 페이지로 이동합니다. 언어를 추가한 뒤 다시 제출해 주세요.
- 코드에 백준 방화벽에 막히는 문자열이 있으면 직접 제출을 안내합니다.
- 제출 탭을 제출 전에 닫았다면 다시 "제출하기"를 눌러 주세요.

## 채점 결과가 풀이 화면에 안 떠요

- 채점 중에는 풀이 화면에 도는 표시가 보입니다. 채점이 끝나면 뒤쪽 제출 탭이 저절로 닫히고 결과가 나옵니다.
- 결과를 읽기 전에 제출 탭을 닫았다면 "결과를 아직 못 받았어요"의 **결과 다시 확인**을 눌러 주세요. 내 채점 현황을 뒤쪽 탭으로 열어 결과를 읽어 옵니다.
- 백준 로그인이 풀려 있으면 결과를 읽을 수 없습니다.

## 백준과 실행 결과가 달라요

브라우저 실행은 백준 채점 서버와 다릅니다. 최종 결과는 항상 백준 채점입니다.

- **시간**: 브라우저가 더 느릴 수 있어 문제 시간 제한의 3배(최대 10초)까지 기다립니다.
- **메모리**: 메모리 제한은 검사하지 않습니다.
- **재귀 깊이**: C, C++, Java는 약 1만 단계까지 안정적입니다. 백준에서는 더 깊이 될 수 있습니다.
- **C++**: 예외(`throw`, `try`)를 쓸 수 없습니다. 백준 제출에서는 정상 동작합니다.
- **Java**: `String.format("%.2f")` 반올림이 조금 다를 수 있고, 예외가 나면 이름만 보입니다. 컴파일러가 최신이라 Java 8에서 안 되는 문법(`var` 등)이 여기서는 될 수 있습니다.
- **TypeScript**: 타입을 지우고 JavaScript로 실행해서 타입 검사를 하지 않습니다. 타입 오류는 백준에서 컴파일 에러가 될 수 있습니다.
- **Python**: 표준 라이브러리만 쓸 수 있습니다.

차이가 이상하면 [실행 결과가 백준과 달라요](https://github.com/vi-wolhwa/cote-in-baekjoon/issues/new?template=2-run-diff.yml)로 알려 주세요.

## 어떤 언어를 쓸 수 있나요?

언어 선택 목록은 **브라우저에서 실행**과 **제출만** 두 묶음으로 나뉩니다.

- **브라우저에서 실행**: C99, C11, C++14, C++17, C++20, Python 3, PyPy3, Java 8, Java 11, JavaScript, TypeScript. **코드 실행**으로 예제를 돌려 본 뒤 제출합니다.
- **제출만**: Kotlin (JVM), Rust 2021, Go, Swift, C#, Ruby. 브라우저에서 실행할 수 없어 **코드 실행**이 꺼져 있습니다. 제출하면 백준이 채점합니다.
- C++14·C++17·C++20, Java 8·Java 11, C99·C11은 같은 코드를 함께 씁니다. 표준만 바꿔 실행하고 제출할 수 있습니다.
- **solution 함수**는 C++, Java, Python, JavaScript에서 쓸 수 있습니다. C, TypeScript와 제출만 되는 언어는 표준 입출력으로 풉니다.

다른 언어가 필요하면 [기능 제안](https://github.com/vi-wolhwa/cote-in-baekjoon/issues/new?template=3-feature.yml)으로 알려 주세요.

## solution 함수로 풀고 싶어요 (입출력 형식)

언어 선택 옆 **solution 함수**가 켜져 있으면 `solution(a, b)`처럼 함수만 작성합니다. 표준 입력을 읽고 결과를 출력하는 **입출력 코드**는 확장이 붙여서 실행하고 제출합니다.

- 에디터 위 **입출력 형식**을 열면 매개변수와 반환값이 보입니다. 출처는 "직접 정의함", "검증된 형식", "예제로 추론함" 중 하나입니다. 추론한 형식이 틀렸다면 표나 JSON으로 고쳐 **저장**하세요. 형식은 예제를 모두 읽고 다시 쓸 수 있어야 저장됩니다.
- 형식을 알 수 없는 문제는 스위치가 꺼진 채 표준 입출력으로 열립니다. **형식 만들기**로 직접 정의하거나, **AI에게 물어볼 프롬프트 복사**로 받은 JSON을 **형식 붙여넣기**로 넣을 수 있습니다. 인터랙티브·함수 구현 문제는 표준 입출력으로만 풉니다.
- 스위치를 끄고 켜도 코드는 사라지지 않습니다. 두 방식의 코드를 따로 저장합니다.
- 백준에는 함수와 입출력 코드를 합친 코드가 제출되어 **내 소스**에 입출력 코드도 보입니다. C++은 `bits/stdc++.h`와 `using namespace std;`, Java는 `java.util.*`·`java.io.*` import가 앞에 붙고, Java 함수는 `class Solution` 안에 씁니다.
- solution 함수 안에서 출력하면 답과 섞여 틀릴 수 있습니다. JavaScript에서 `long` 값이 2^53을 넘으면 BigInt로 전달됩니다.
- 고친 형식을 다른 사람도 쓰게 하려면 **형식 제안**을 누르세요. 문제 번호와 형식만 담긴 이슈가 열립니다(코드·문제 본문은 보내지 않습니다).

## 모의 시험은 어떻게 보나요?

여러 문제를 제한 시간 안에 푸는 시험입니다. 팝업의 **모의 시험** 탭이나 백준 문제 메뉴의 "모의시험"에서 시작합니다.

- 난이도, 알고리즘, 문제 수, 제한 시간을 고르면 **solved.ac**에서 조건에 맞는 문제를 무작위로 고릅니다. 처음 한 번은 solved.ac 접근 허용을 묻습니다.
- **포함할 문제**에 문제 번호를 넣으면 조건과 관계없이 그 문제가 꼭 나옵니다. 넣은 문제는 문제 수보다 많을 수 없습니다. 백준 메뉴의 "모의시험"으로 열면 그 문제가 미리 들어가 있고, 뺄 수 있습니다.
- 백준에 로그인한 채로 백준 문제 페이지를 한 번 열면 아이디를 알게 되어 **이미 푼 문제를 뺄 수** 있습니다.
- 시험을 시작하면 문제를 하나씩 뒤쪽 탭으로 열어 읽습니다. 탭이 잠깐씩 보였다 닫혀도 정상입니다.
- 시험 중 **제출하기**는 백준에 제출하지 않고 **답안을 저장**합니다. 다시 누르면 지금 코드로 바뀝니다.
- 시험이 끝나면(시험 종료 또는 시간 끝) 저장한 답안을 **하나씩 차례로** 백준에 제출하고 결과 화면에 채점 결과를 보여 줍니다. 다 낼 때까지 결과 화면을 닫지 말아 주세요.
- 제출 탭에 보안 확인 등이 나오면 "직접 확인이 필요해요"가 뜹니다. **직접 확인**을 눌러 직접 제출해 주세요. 실패한 답안은 **다시 제출**로, 결과를 못 받은 답안은 **결과 다시 확인**으로 다시 읽어 옵니다.
- "조건에 맞는 문제가 N개뿐이에요"가 나오면 난이도나 알고리즘을 더 고르거나 문제 수를 줄여 주세요.

## 코드가 사라졌어요

- 코드는 문제·언어별로 브라우저에 자동 저장됩니다. 언어를 바꿨다면 원래 언어로 돌아가 보세요.
- **확장을 삭제하면 저장된 코드도 지워집니다.** 팝업의 **백업** 탭에서 파일로 내보내 두세요.

## 첫 실행이 느려요

Python, C, C++, Java는 처음 실행할 때 실행 환경을 불러오느라 1~7초 걸립니다. 그다음부터는 빠릅니다.
