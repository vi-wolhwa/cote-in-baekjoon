# ADR-0005: 모의 시험

- 상태: 승인 (2026-11-24)
- 관련: M4, #99 ~ #102, PRD 6장 M4

## 배경

여러 문제를 시간 제한 안에 푸는 모의 시험을 만든다. 제품 책임자가 정한 것(2026-11-24):

- 시험 중 제출 결과는 **시험이 끝난 뒤** 공개한다.
- 문제 세트는 solved.ac 조건(티어, 알고리즘, 문제 수)으로 고르고, **로그인된 백준 아이디로 이미 푼 문제를 뺀다**(끌 수 있음).
- 시작은 팝업의 '모의 시험' 탭과 백준 문제 메뉴의 '모의시험'(코딩테스트와 제출 사이).
- 화면은 #99의 시안(시험 만들기, 시험 화면, 결과 화면)을 따른다.

## 결정

**문제 고르기: solved.ac 검색 API**
- `GET https://solved.ac/api/v3/search/problem?query=…&sort=random&page=1`
  - 티어 `*s5..g1`, 알고리즘 `(#dp|#greedy)`, 이미 푼 문제 빼기 `!s@아이디`, 한국어 문제 `lang:ko`
  - 결과에서 앞의 N개를 쓴다. 모자라면 사용자에게 조건을 넓히라고 안내한다.
- 권한: `optional_host_permissions`에 `https://solved.ac/*`를 두고, 처음 시험을 만들 때 `permissions.request`로 묻는다. 설치할 때 경고가 늘지 않는다.
- 요청은 사용자가 '시험 시작'을 누를 때만 보낸다. 자동 갱신이나 미리 받아 두기는 하지 않는다.

**백준 아이디**
- 콘텐츠 스크립트가 백준 페이지의 로그인 정보(상단 사용자 링크)를 읽어 `boj:handle`로 저장한다. 사용자가 백준에 들어갈 때마다 갱신한다.
- 아이디를 모르면 '이미 푼 문제 빼기'를 끄고 이유를 보여 준다.

**문제 본문**
- 시험 화면에서 사용자가 그 문제를 처음 열 때 `https://www.acmicpc.net/problem/{번호}`를 가져와 기존 파서(`parseProblem`)로 읽는다. 쿠키는 보내지 않는다(`credentials: 'omit'`).
- 가져온 결과는 시험 기록에 저장해 다시 요청하지 않는다. 크롤링(미리 여러 문제를 받아 두기)은 하지 않는다.
- 권한: 확장 페이지에서 백준 페이지를 가져오려면 `host_permissions`에 `acmicpc.net`이 필요하다. 콘텐츠 스크립트 때문에 이미 같은 사이트 경고가 있으므로 설치 경고는 늘지 않는다.

**제출과 결과 숨기기**
- 제출은 지금 흐름(공식 제출 창, 자동 제출, ADR-0002)을 그대로 쓴다.
- 시험 중 제출이면 감시 기록(`cib:watch:{문제}`)에 `hideResult`를 표시한다. 제출 창의 채점 현황 페이지는 결과 대신 "제출했습니다. 결과는 시험이 끝나면 공개됩니다."로 덮고, 결과를 읽으면 지금처럼 창을 닫는다.
- 시험 화면은 결과 대신 '제출함'만 보인다. 결과는 `judge:{문제}`에 평소처럼 저장되고, 결과 화면에서 시험 시작 이후의 결과만 모아 보여 준다.

**시간**
- 남은 시간은 시작 시각과 제한 시간으로 계산한다(타이머와 같은 방식, `src/ide/timer.ts`). 0이 되면 자동으로 끝난다. 끝난 뒤 들어온 결과도 결과 화면에 보이지만 '시간 뒤 제출'은 없다(끝나면 제출 버튼을 막는다).

**저장**

| 키 | 내용 | 백업 |
| --- | --- | --- |
| `exam:{시험 id}` | 조건, 문제 목록(번호·제목·solved.ac 레벨·가져온 본문), 시작·끝 시각, 제한 시간, 다시 볼 문제, 문제별 마지막 제출(언어, 시각) | 포함 |
| `ui:exam-draft` | 마지막으로 고른 조건 | 포함 |
| `boj:handle` | 로그인된 백준 아이디 | 제외(다시 읽으면 됨) |
| 코드 | 연습과 같은 `code:{문제}:{언어}` | 포함 |

**화면**
- 시험 만들기 폼은 하나의 컴포넌트로 만들어 팝업 '모의 시험' 탭과 `exam.html#setup`(백준 메뉴 '모의시험'이 여는 새 탭, 그 문제를 포함)에서 함께 쓴다.
- 시험 화면 `exam.html#{시험 id}`: 풀이 화면 구성(문제·에디터·실행 결과)에 문제 번호 줄(✓ 제출함, ⚑ 다시 볼 문제)과 사이드바의 남은 시간을 더한다. 상단에 '시험 종료'.
- 결과 화면 `exam.html#{시험 id}/result`: 맞은 문제 수, 걸린 시간, 문제별 결과·언어·제출 시각.

## 결과

- solved.ac가 응답하지 않거나 권한을 거절하면 시험을 만들 수 없다. 팝업에서 이유와 다시 시도를 보여 준다.
- 문제 본문을 시험 중에 처음 열 때 백준 페이지를 한 번 가져온다. 사용자 동작(문제 열기) 때만이다.
- 시험 중 제출은 실제 백준 제출이다. 결과를 숨겨도 백준 채점 현황에는 남는다.
