# 저장 방식과 한계

이 문서는 #34에서 분석한 결과다. 사용자가 작성 중인 코드와 테스트 케이스가 어떻게 유지되는지, 수백·수천 문제에서도 문제가 없는지 정리한다.

## 1. 무엇을 어디에 저장하나

모든 데이터는 사용자 브라우저의 확장 전용 저장소에만 있다. 서버로 보내지 않는다.

| 키 | 내용 | 저장소 | 언제 쓰나 |
|---|---|---|---|
| `code:{문제}:{언어}` | 작성 중인 코드 | `chrome.storage.local` | 입력을 멈추고 0.4초 뒤 |
| `code:{문제}:{언어}:fn` | solution 함수 모드의 코드(ADR-0006). 표준 입출력 코드와 따로 둔다 | `chrome.storage.local` | 입력을 멈추고 0.4초 뒤 |
| `format:{문제}` | 사용자가 저장한 입출력 형식(DSL v1 JSON, 백업에 포함) | `chrome.storage.local` | 형식 카드에서 저장할 때 |
| `ui:solution` | solution 함수 켜기/끄기(기본 켬, 백업에 포함) | `chrome.storage.local` | 스위치를 바꿀 때 |
| `cases:{문제}` | 직접 추가한 테스트 케이스(solution 함수 모드도 표준 입출력으로 저장) | `chrome.storage.local` | 대화상자에서 확인을 누를 때 |
| `judge:{문제}` | 마지막 채점 결과 1건 | `chrome.storage.local` | 채점 결과를 읽을 때 |
| `ui:keymap`, `ui:split` | 키맵, 패널 크기 | `chrome.storage.local` | 바꿀 때 |
| 제출 대기 코드 | 제출 페이지로 넘길 코드 | `chrome.storage.session` | 제출하기를 누를 때. 넘기면 바로 지우고, 10분이 지나면 버린다 |

## 2. 보존 기간

`chrome.storage.local`에는 **유효 기한이 없다.** 다음 경우에만 지워진다.

| 경우 | 지워짐 |
|---|---|
| 브라우저 재시작, 컴퓨터 재부팅 | 유지 |
| 확장 업데이트 | 유지 |
| 브라우저의 '인터넷 사용 기록 삭제'(쿠키, 캐시) | 유지. 확장 저장소는 웹사이트 데이터와 별개다 |
| **확장 삭제** | **모두 삭제** |
| 브라우저 프로필 삭제 | 모두 삭제 |

`chrome.storage.session`은 브라우저를 닫으면 지워진다. 제출 대기 코드처럼 잠깐만 필요한 데이터에만 쓴다.

## 3. 용량

**기본 한도**
- `chrome.storage.local`의 기본 한도는 확장 하나당 10MB다(Chrome 114 이상).
- 키 개수와 항목 하나의 크기에는 따로 제한이 없다.

**예상 사용량** (문제 하나 기준)

| 항목 | 일반적인 크기 |
|---|---|
| 코드 | 1~5KB |
| 테스트 케이스 | 0~10KB |
| 채점 결과 | 약 0.2KB |

- 문제당 평균 5KB로 잡으면 1,000문제는 약 5MB, 2,000문제는 약 10MB다.
- 기본 한도로는 **2,000문제 안팎에서 한도에 닿을 수 있다.**

**조치 (#34)**
- **`unlimitedStorage` 권한을 추가했다.** 10MB 한도가 사라지고 디스크 여유 공간까지 쓸 수 있다. 설치 시 추가 경고 문구는 나오지 않는 권한이다.
- **저장 실패를 알린다.** 저장이 실패하면(한도 초과, 디스크 부족 등) 에디터 위에 경고를 띄워 사용자가 코드를 따로 보관하게 한다. 전에는 실패해도 아무 표시가 없었다.

## 4. 남은 위험과 후속 작업

- **확장을 삭제하면 모든 코드가 사라진다.** 옵션 페이지(풀이 화면 상단 "백업과 복원")에서 코드, 테스트 케이스, 채점 결과, 설정을 JSON 파일로 내보내고 가져올 수 있다(#42). 가져올 때 합치기(지금 데이터 유지, 없는 것만 추가)와 덮어쓰기 중에서 고른다. 파일은 신뢰하지 않는 입력으로 보고 키와 값을 모두 검사한다(`src/shared/backup.ts`).
- **동기화는 하지 않는다.** `chrome.storage.sync`는 전체 100KB 한도라 코드 저장에 맞지 않는다. 여러 기기 간 동기화가 필요하면 별도 방식(예: GitHub Gist)을 검토해야 한다.
- 언어가 늘면(M2) `code:{문제}:{언어}`가 언어별로 따로 저장된다. 용량 계산은 언어 수만큼 늘어나지만 `unlimitedStorage`로 감당된다.
