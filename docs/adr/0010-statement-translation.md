# ADR-0010: 외국어 문제 자동 번역

- 상태: 승인 (2026-11-24)
- 관련: `src/ide/translate/`, 화면 명세 §7

## 배경

백준에는 영어, 일본어, 폴란드어 등 한국어가 아닌 문제가 많다. 제품 책임자가 다른 언어로 된 문제를 자동으로 번역하고, 원문으로 보는 토글을 두라고 요청했다(2026-11-24).

## 결정

- **브라우저 내장 번역기**: 브라우저의 Translator·LanguageDetector API를 쓴다. 기기 안에서 번역하므로 문제 본문이 외부 서버로 가지 않고, 비용과 API 키가 없다. 외부 번역 서비스(유료 API, 비공식 엔드포인트)는 쓰지 않는다.
- **언어 감지**: LanguageDetector가 준비되어 있으면 그것으로, 아니면 글자 체계(한글·가나·한자·키릴·라틴)로 짐작한다. 한국어 문제에는 아무것도 보이지 않는다.
- **번역 시점**
  - 번역기가 바로 쓸 수 있으면 문제를 열 때 자동으로 번역한다.
  - 번역 모델을 처음 내려받아야 하면 '한국어로 번역' 버튼을 보인다. API가 다운로드에 사용자 클릭을 요구하기 때문이다. 한 번 받으면 다음 문제부터는 자동이다.
- **원문 보기**: 번역 막대의 '번역 / 원문' 토글로 바꾼다. 고른 쪽을 기억한다(`ui:translate`). 원문을 고르면 다음 문제는 번역하지 않고 버튼만 보인다.
- **구조 보존**
  - 문단·목록 항목·표 칸마다 한 문장으로 번역한다. 수식(`$…$`, `\(…\)`), 코드, 위·아래 첨자, 그림, 하위 블록은 번호 표시(`[3]`)로 바꿨다가 번역 뒤 되돌린다.
  - 번역기가 표시를 잃으면 그 블록은 글 조각마다 따로 번역해, 마크업이 늘 남는다.
  - 예제 입출력과 `pre`는 번역하지 않는다.
- **프레임 권한**: 풀이 화면은 백준 페이지의 iframe(다른 출처)이라 `allow="translator; language-detector"`를 준다.

## 결과

- Chrome(데스크톱)에서는 번역된다. 내장 번역기가 없거나 그 언어 쌍을 지원하지 않는 브라우저(현재 Edge 등)는 원문을 보이고 그 사실을 알린다.
- 기계 번역이므로 막대에 "…에서 기계 번역했어요"를 적고, 원문으로 언제든 바꿀 수 있다.
- 번역 품질은 브라우저 모델에 달려 있다. 테스트는 가짜 번역기로 흐름과 구조 보존만 확인한다.
