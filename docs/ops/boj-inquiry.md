# 백준 운영사 문의 초안: 제출 페이지 자동 입력 허용 여부

ADR-0002의 남은 위험(자동 입력)을 확인하기 위한 문의다. 웹스토어 공개(M3) 전에 제품 책임자가 보낸다.

- 보내는 곳: 백준 온라인 저지 고객센터 또는 운영사(데이원컴퍼니) 문의 창구
  - 정확한 창구는 [백준 도움말](https://help.acmicpc.net/)에서 확인한다.
- 보내는 사람: 제품 책임자 본인 계정·이메일
- 상태: 초안 (아직 보내지 않음)

---

**제목**: 브라우저 확장 프로그램의 제출 폼 자동 입력이 '자동 제출 도구'에 해당하는지 문의드립니다

안녕하세요. 백준 온라인 저지를 이용하고 있는 사용자입니다.

백준 문제를 기업 코딩테스트와 비슷한 화면에서 풀 수 있도록 돕는 크롬 확장 프로그램을 개인적으로 만들고 있습니다. 공개 배포 전에 이용 규칙 위반 여부를 확인하고 싶어 문의드립니다.

**확장 프로그램이 하는 일**

1. 사용자가 연 문제 페이지 위에 코드 편집 화면을 띄웁니다. 백준 서버에 별도 요청을 보내지 않고, 이미 열린 페이지의 내용만 사용합니다.
2. 예제 입력으로 코드를 실행해 보는 기능은 사용자의 브라우저 안에서만 동작합니다.
3. 사용자가 '제출하기'를 누르면 공식 제출 페이지(`/submit/문제번호`)를 작은 창으로 엽니다. 그 페이지의 언어 선택과 코드 입력란을 사용자가 작성한 코드로 미리 채웁니다.
4. **제출 버튼은 사용자가 직접 누릅니다.** 확장은 제출 버튼을 누르거나 제출 요청을 직접 보내지 않습니다.
5. 제출 후 사용자가 보고 있는 채점 현황 페이지에서 결과를 읽어 편집 화면에 표시합니다.
   - 실시간 채점 현황이 연결되지 않을 때(오류 4004)에 한해, 방금 낸 제출 1건의 결과를 채점 현황 페이지와 같은 요청(`/status/ajax`)으로 확인합니다.
   - 1~5초 간격으로, 최종 결과가 나오면 멈추고, 최대 10분까지만 확인합니다.

**문의 내용**

이용 규칙의 '자동 제출 도구' 정의는 공식 `/submit` 경로에서 사용자가 직접 제출 버튼을 누르지 않는 방식이라고 이해했습니다. 위 3번처럼 공식 제출 페이지의 입력란을 미리 채우고 사용자가 직접 제출 버튼을 누르는 방식이 허용되는지 확인 부탁드립니다.

또한 다음 두 가지도 확인 부탁드립니다.

- 위 5번의 채점 결과 확인 방식(제출 1건, 최종 결과까지만)이 이용 규칙에 어긋나지 않는지
- 향후 확장 편집 화면의 버튼 하나로 공식 제출 경로를 통해 제출하는 방식을 허용하실 수 있는지, 또는 이를 위한 공식 방법이 있는지

허용되지 않는 부분이 있다면 코드를 클립보드에 복사하고 제출 페이지만 열어 주는 방식 등으로 바꾸겠습니다. 알려 주시면 따르겠습니다.

감사합니다.
