# 웹스토어 제출 자료

크롬 웹스토어 개발자 대시보드에 넣을 내용의 초안입니다. 게시는 #206에서 제품 책임자가 승인한 뒤에만 합니다.

## 스토어 등록정보 탭

- **이름**: 코딩테스트 in 백준
- **카테고리**: 교육
- **언어**: 한국어
- **아이콘**: `public/icon/128.png`

**짧은 설명** (132자 이내)

> 백준 문제를 코딩테스트 시험 화면처럼 풀어 보세요. 문제와 에디터를 한 화면에 두고, 예제는 브라우저에서 실행하고, 제출은 백준으로 바로 보냅니다.

**자세한 설명**

```
백준(acmicpc.net) 문제 페이지에서 "코딩테스트"를 누르면, 기업 코딩테스트와 비슷한 풀이 화면이 열립니다. 실제 시험처럼 문제를 읽고, 코드를 쓰고, 예제로 확인한 뒤 제출해 보세요.

※ 이 확장 프로그램은 백준 온라인 저지(스타트링크)와 관계없는 비공식 프로그램입니다.

■ 한 화면에서 풀기
- 왼쪽에 문제와 제출 기록, 오른쪽에 에디터와 실행 결과
- 수식, 예제 입력·출력을 그대로 표시. 영어 등 외국어 문제는 한국어로 번역(원문 보기 가능)
- 다크·라이트 테마, sublime·vim·emacs 키맵, 스톱워치와 타이머

■ 브라우저에서 바로 실행
- C·C++(14/17/20), Python 3, Java 8/11, JavaScript, TypeScript
- 예제와 직접 추가한 테스트 케이스로 실행하고, 통과 여부와 기댓값과의 차이를 알려 줍니다
- 코드는 네트워크가 막힌 격리된 공간에서 실행됩니다. 실행 환경이 확장 프로그램에 들어 있어 따로 설치할 것이 없습니다
- Kotlin, Rust, Go, Swift, C#, Ruby는 작성과 제출만 됩니다

■ solution 함수로 풀기
- 입출력 코드 없이 solution 함수만 작성하는 코딩테스트 방식으로 풀 수 있습니다
- 많이 푼 문제는 입출력 형식이 준비되어 있고, 예제는 '입출력 예' 표로 보여 줍니다

■ 모의 시험
- 난이도와 알고리즘을 골라 시간 제한이 있는 시험 세트를 만듭니다(solved.ac 공개 정보 사용)
- 시험 중에는 아무것도 제출하지 않고, 시험이 끝나면 답안을 백준에 차례로 제출해 결과를 보여 줍니다

■ 백준으로 제출
- "제출하기"를 누르면 백준 제출 페이지가 뒤쪽 탭에서 열리고 언어와 코드가 채워집니다
- 제출 버튼까지 자동으로 누릅니다. 제출 직전 잠깐 취소할 수 있습니다
- 채점 중에는 풀이 화면에 표시가, 끝나면 결과가 바로 나타납니다

■ 제출 기록
- 그 문제의 내 제출, 맞힌 사람, 숏코딩 목록을 풀이 화면 안에서 봅니다. 보기를 열 때 백준 목록을 한 페이지씩 읽습니다
- 공개된 코드를 열어 보고, 지난 코드를 편집기로 불러올 수 있습니다

■ 내 코드는 내 브라우저에
- 작성 중인 코드와 테스트 케이스는 브라우저에만 저장됩니다
- 운영자 서버가 없고, 사용 통계·광고를 쓰지 않습니다. 외국어 문제를 번역할 때만 문제 문장을 구글 번역으로 보냅니다

최종 채점은 항상 백준에서 이루어지며, 브라우저 실행 결과(시간, 메모리)는 백준 채점과 다를 수 있습니다.

문의와 제안: (공개 창구 결정 뒤 기입, #200)
```

> 자동 제출은 항상 켜져 있다(2026-11-24 결정). 소개 문구에서 이 사실을 숨기지 않는다.

## 개인정보 보호 관행 탭

**단일 목적**

> 백준(acmicpc.net) 문제를 코딩테스트와 같은 풀이 화면에서 풀도록 돕습니다. 문제 읽기, 코드 작성과 예제 실행, 백준 제출과 채점 결과·제출 기록 확인, 백준 문제로 만든 모의 시험이 모두 이 풀이 화면 안의 기능입니다.

**권한별 사용 이유**

| 항목 | 답변 |
| --- | --- |
| `storage` | 사용자가 작성한 코드, 테스트 케이스, 설정, 마지막 채점 결과를 브라우저에 저장합니다. |
| `unlimitedStorage` | 모의 시험 기록(시험마다 문제 본문 최대 8개)과 테스트 케이스가 쌓여도 10MB 제한에 걸리지 않도록 합니다. 데이터는 기기 밖으로 나가지 않습니다. |
| 호스트 권한 (acmicpc.net) | 문제 페이지에 풀이 화면을 띄우고, 제출 페이지에 언어와 코드를 채우고, 사용자 제출의 채점 결과를 읽습니다. 모의 시험에서는 사용자가 연 문제의 페이지를 뒤쪽 탭으로 한 번 열어 내용을 읽고 닫습니다. |
| `activeTab` | 툴바 팝업을 열었을 때 지금 탭의 주소를 읽어, 백준 문제 페이지라면 그 문제를 바로 풀 수 있게 합니다. 팝업을 연 탭에만 적용됩니다. |
| 선택 호스트 권한 (solved.ac) | 모의 시험을 만들 때 사용자가 고른 조건에 맞는 문제를 solved.ac 공개 API에서 고릅니다. 처음 시험을 만들 때만 묻습니다. |

**원격 코드 사용**: 아니요. 모든 스크립트와 실행 환경(Pyodide, Clang)은 패키지에 포함되어 있습니다.

**데이터 사용**: 운영자는 아무것도 수집하지 않습니다. 다만 번역 기능이 외국어 문제 본문을 구글 번역으로 보내므로(#201) 아래처럼 신고합니다.

- **웹사이트 콘텐츠: 해당** — 사용 목적 '앱 기능'. 외국어 문제를 한국어로 번역하려고 그 문제 본문을 구글 번역(`translate.googleapis.com`)에 보냅니다. 코드·아이디·쿠키는 보내지 않고, 운영자는 받지 않습니다.
- 나머지(개인 식별 정보, 건강, 금융, 인증 정보, 개인 커뮤니케이션, 위치, 웹 기록, 사용자 활동): 해당 없음

> 백준 문제 페이지는 화면에 보여 주려고 읽기만 하고 기기 밖으로 보내지 않습니다. 번역 방식을 바꾸면(#201 결정) 이 항목도 고칩니다.

**인증 항목**: 세 가지 모두 체크합니다.

- 승인된 사용 사례 외에 사용자 데이터를 제3자에게 판매하거나 전송하지 않음
- 단일 목적과 관계없는 목적으로 사용자 데이터를 사용하거나 전송하지 않음
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음
